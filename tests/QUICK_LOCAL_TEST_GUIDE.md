## ⚠️ 常见问题

### 问题1：连接被拒绝（Connection refused）

**原因**：ChatServer未启动或端口不是8090

**解决**：
```bash
# 检查ChatServer是否运行
ps aux | grep chat_server

# 检查8090端口是否监听
netstat -tlnp | grep 8090
```

### 问题2：连接成功率低（< 90%）

**原因**：系统文件描述符限制

**解决**：
```bash
# 查看当前限制
ulimit -n

# 临时增加限制
ulimit -n 65535
```

### 问题3：Redis/MySQL连接失败

**影响**：不影响TCP连接测试，但业务逻辑可能无法正常工作

**说明**：
- 压测脚本只测试TCP连接和消息收发
- 不需要Redis/MySQL也能测试基本性能
- 如果需要完整功能测试，需要启动Redis和MySQL
